🚀 Life OS

A personal productivity dashboard built with Python and Streamlit.

Life OS brings everyday life management into one simple interface.

✨ Features

- 👤 Profile & Account Management
- ✅ Task Manager
- 💰 Expense Manager
- 📝 Notes Manager
- 🔥 Habit Tracker
- 📁 File Manager
- 📊 Dashboard & Statistics
- ⚙️ Settings
- 💾 Local JSON Data Storage

🛠️ Tech Stack

- Python
- Streamlit
- JSON
- Pandas

🚀 Getting Started

Clone the repository:

git clone https://github.com/daksh19234/Life-os.git
cd Life-os

Install dependencies:

pip install streamlit pandas

Run the application:

streamlit run app.py

The application will open in your browser.

📂 Data Storage

Life OS currently stores application data locally using:

lifeos_data.json

User-created files are stored in:

lifeos_files/

These files are excluded from Git using ".gitignore".
